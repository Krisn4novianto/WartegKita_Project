# WartegKita SDLC

## 1. Planning
Masalah: customer kesulitan membeli makanan warteg ketika sibuk.
Solusi: platform online untuk discovery, ordering, payment, dan tracking.

## 2. Analysis
Aktor:
- Customer
- Seller
- Admin

## 3. Design
Frontend React + TypeScript.
Backend Golang + Gin.
Database PostgreSQL.

## 4. Development
Urutan:
1. Authentication
2. Seller & Menu
3. Customer Discovery
4. Cart & Checkout
5. Order Management
6. Payment
7. Admin

## 5. Testing
- Unit testing
- API testing
- Integration testing
- User acceptance testing

## 6. Deployment
Docker, PostgreSQL, backend service, frontend hosting.

## 7. Maintenance
Monitoring, bug fixing, security update, feature improvement.
